# Naveenkumar M. – Animated Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Run it locally (pick one)

### Option 1: VS Code Live Server (easiest)
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension (by Ritwick Dey). VS Code will suggest it.
3. Right-click `index.html` > "Open with Live Server".
4. Chrome opens at http://127.0.0.1:5500 (or http://localhost:5500).

### Option 2: Terminal (needs Node.js)
Open the VS Code terminal (Ctrl + `) and run:

    npm start

Then open http://localhost:5500 in Chrome.

### Option 3: Terminal (needs Python)

    python -m http.server 5500

Then open http://localhost:5500 in Chrome.
